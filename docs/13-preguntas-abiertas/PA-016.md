# PA-016 — Idiomas futuros y previsión de siguientes fases tras la web corporativa

## Contexto y evidencia
El requerimiento inicial indica que *«solo se va a hacer una web inicialmente»*, pero `CLAUDE.md` provenía de una plataforma con app y web de gestión. Conviene confirmar qué puede crecer después sin sobrediseñar la Fase 1.

## Preguntas concretas
1. ¿El idioma será exclusivamente **español (`es-ES`)** o se contempla asturiano / inglés en futuras fases?
2. ¿A medio plazo se prevé añadir algún módulo adicional (p. ej. portal de cliente para seguimiento de obra, descarga de dossiers o área privada) que deba tenerse en cuenta a nivel de dominio/subdominio?
