# RF-SERV-001 — Hub de servicios y 6 páginas principales por especialidad

El sistema debe publicar una página concentradora en `/servicios/` y seis páginas dedicadas por especialidad (`/reformas-integrales-en-asturias/`, `/reformas-de-cocinas-en-asturias/`, `/reformas-de-banos-en-asturias/`, `/construccion-de-viviendas-en-asturias/`, `/reformas-parciales-en-asturias/` y `/reforma-de-locales-comerciales-en-asturias/`), corrigiendo las erratas detectadas en el contenido heredado como el encabezado equivocado de Reformas Parciales.
