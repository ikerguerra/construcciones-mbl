# RF-PROY-001 — Galería filtrable de proyectos y fichas individuales activables

El sistema debe ofrecer en `/proyectos/` una galería filtrable mediante pestañas (`Todos`, `Reforma integral`, `Cocinas`, `Baños y duchas`, `Locales comerciales`) con imagen optimizada, título de obra, municipio y resumen técnico, así como permitir acceder a una ficha individual detallada por proyecto (`/proyectos/[slug]/`) con reto, solución técnica, trabajos ejecutados, galería fotográfica y formulario de presupuesto; dicha ficha individual podrá activarse o desactivarse por configuración (a nivel global o por proyecto individual).
