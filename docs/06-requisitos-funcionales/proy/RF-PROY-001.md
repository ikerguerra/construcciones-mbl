# RF-PROY-001 — Galería de proyectos realizados con filtrado por categoría

El sistema debe ofrecer en `/proyectos/` una galería filtrable mediante pestañas (`Todos`, `Reforma Integral`, `Cocinas`, `Baños` y otras tipologías disponibles) que muestre tarjetas visuales con imagen optimizada, título de obra, municipio en Asturias y descripción técnica breve.
