# Glosario

| Término | Definición en el contexto de Construcciones MBL |
|---|---|
| **AEO** (*Answer Engine Optimization*) | Optimización del contenido y la estructura semántica (resúmenes directos, tablas comparativas, FAQs y `FAQPage`) para aparecer en respuestas directas, fragmentos destacados (*featured snippets*) y asistentes de voz o respuesta rápida. |
| **Astro / Islas (*Islands*)** | Framework web orientado a contenido que genera HTML estático sin JavaScript por defecto y solo hidrata componentes interactivos puntuales (simulador, filtros, formularios, modales). |
| **Canonical** | Etiqueta `<link rel="canonical">` que indica a buscadores e IAs cuál es la URL oficial única de un recurso para evitar contenido duplicado. |
| **CTA** (*Call To Action*) | Elemento interactivo orientado a conversión (solicitar presupuesto, calcular reforma, llamar al `684 675 898`, abrir WhatsApp). |
| **CWV** (*Core Web Vitals*) | Métricas de experiencia de usuario medidas por Google: `LCP` (carga del elemento principal), `INP` (latencia de interacción) y `CLS` (estabilidad visual). |
| **E-E-A-T** | Señales de Experiencia, Conocimiento técnico (*Expertise*), Autoridad y Confianza (*Trustworthiness*) evaluadas en contenidos de reformas, normativa y precios. |
| **GEO** (*Generative Engine Optimization*) | Optimización para motores de búsqueda generativos (ChatGPT Search, Perplexity, Google AI Overviews, Claude) mediante entidades explícitas en JSON-LD, autoría verificable, datos cuantitativos claros y texto semántico limpio. |
| **GBP** (*Google Business Profile*) | Ficha local de Construcciones MBL en Google Maps (`Place ID: ChIJN_H9_Jyih2MRXyPsrrG4cWg`). |
| **Index Bloat** | Acumulación de URLs de escaso valor (como las 340 páginas `/tag/` o `/mensaje-enviado/`) que consumen presupuesto de rastreo y diluyen autoridad SEO. |
| **JSON-LD / Schema.org** | Marcado de datos estructurados embebido en `<script type="application/ld+json">` para describir empresa, servicios, artículos, FAQs y migas de pan. |
| **Lead** | Solicitud de contacto o estimación de reforma enviada por un cliente potencial mediante formulario, simulador o canal directo. |
| **NAP** | Consistencia exacta de *Name, Address, Phone* (`MBL CONSTRUCCIONES S.L.` / `Construcciones MBL`, `Av. Argentina 132 (Cristasa of.221), 33213 Gijón`, `+34 684 675 898`) en toda la web, Schema y directorios. |
| **SEO Local** | Estrategia para captar búsquedas con intención geográfica en Asturias, Gijón, Oviedo y Avilés. |
| **SSG** (*Static Site Generation*) | Pre-renderizado de todas las páginas en tiempo de compilación (*build*) para servir HTML instantáneo desde CDN/edge. |
| **TL;DR / Respuesta directa** | Bloque breve al inicio de artículos y servicios que sintetiza la respuesta clave en 40–60 palabras para usuarios y motores AEO/GEO. |
