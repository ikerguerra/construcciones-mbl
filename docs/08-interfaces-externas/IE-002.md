# IE-002 — Google Tag Manager, GA4, Consent Mode v2 y Search Console

Integración de analítica y seguimiento de conversiones mediante **nuevas cuentas propias** de Google Tag Manager y/o Google Analytics 4 inyectadas por variables de entorno opcionales (`PUBLIC_GTM_ID` y/o `PUBLIC_GA4_ID`, inocuas mientras permanezcan vacías para rellenarlas tras la puesta a punto), subordinada a un **banner de consentimiento nativo ultraligero en español con Google Consent Mode v2** (sustituyendo definitivamente a CookieYes), junto con la verificación de una nueva propiedad en Google Search Console tras el corte DNS (resuelto en [[PA-012]], pendiente solo de verificación operativa en [[PA-015]]).
