# IE-002 — Google Tag Manager, GA4, Consent Mode v2 y Search Console

Integración de analítica y seguimiento de conversiones mediante **nuevas cuentas propias** de Google Tag Manager y/o Google Analytics 4 inyectadas por variables de entorno (`PUBLIC_GTM_ID` y/o `PUBLIC_GA4_ID`), subordinada al gestor de consentimiento conforme a AEPD/RGPD, junto con la verificación de una nueva propiedad en Google Search Console tras el corte DNS para monitorizar indexación y sitemaps.

> [!warning] Hipótesis
> Se asume provisionalmente descartar por completo los identificadores del WordPress anterior, cargar las cuentas propias únicamente tras aceptación o bajo Consent Mode v2 por defecto denegado, y sustituir CookieYes por un gestor ligero nativo. Pendiente de aportar los IDs propios en [[PA-012]] y [[PA-015]].
