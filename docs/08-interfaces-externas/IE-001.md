# IE-001 — Servicio externo de envío y registro de formularios y leads

Interfaz que sustituye a Contact Form 7 (`wpcf7` en WordPress) mediante un endpoint serverless en **Cloudflare Pages Functions** (`/api/lead`) conectado a **Resend** (API HTTP nativa en capa gratuita, óptima para runtime edge) para validar datos, aplicar protección antispam, enviar la notificación comercial a `LEADS_TO_EMAIL` (`info@construccionesmbl.com`), emitir opcionalmente un correo automático de confirmación al solicitante gobernado por la variable de entorno **`SEND_AUTO_REPLY`** (`true` / `false`) y enviar de forma opcional un webhook hacia una nueva hoja Google Sheets propia (`SHEETS_WEBHOOK_URL`), resuelto en [[PA-004]] y [[ADR-005]].

## Contrato lógico de entrada (`SolicitudLead`)
- `origen`: `contacto | simulador | landing-oferta`
- `nombre`, `email`, `telefono`
- `tipo_obra`, `subtipo`, `metros_m2`, `calidad`, `ubicacion`, `trabajos[]`, `plazo`, `mensaje`
- `estimacion_min`, `estimacion_max` (opcional si procede del simulador)
- `acepta_privacidad`: `true` (obligatorio) + `timestamp` + token antispam
