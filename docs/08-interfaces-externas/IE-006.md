# IE-006 — Infraestructura de alojamiento estático, DNS, SSL y capa de redirecciones

Plataforma CDN/edge encargada de servir el sitio estático compilado en Astro bajo `https://construccionesmbl.com/`, aplicar reglas `301`/`410` de latencia mínima, inyectar cabeceras HTTP de seguridad y gestionar la transición DNS sin afectar al correo ni al acceso Webmail existente.

> [!warning] Hipótesis
> Se asume provisionalmente despliegue en plataforma edge compatible con reglas `_redirects` / funciones ligeras y SSL automático, pendiente de [[PA-006]] y [[ADR-007]].
