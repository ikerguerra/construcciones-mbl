# IE-006 — Infraestructura de alojamiento estático, DNS, SSL y capa de redirecciones

Plataforma CDN/edge en **Cloudflare Pages** encargada de servir en producción el sitio estático compilado en Astro bajo `https://construccionesmbl.com/` (sin `www.` y con barra final `/`), ejecutar de forma declarativa las reglas `301`/`410` (`_redirects` y `functions/tag/[[path]].ts`), inyectar cabeceras HTTP de seguridad (`_headers`), alojar las funciones serverless de formularios y gestionar la transición DNS coordinada con el gestor actual de WordPress manteniendo intactos los registros `MX` del correo corporativo (resuelto en [[PA-006]] y [[ADR-007]]). Asimismo, incorpora compatibilidad dual declarativa para el entorno de pre-producción en **Vercel** mediante `vercel.json` (reglas `301` idénticas, rewrite `/tag/:path*` → `/api/tag` con `410 Gone` y cabeceras HTTP equivalentes) y `api/lead.ts` (resuelto en [[PA-024]]).
