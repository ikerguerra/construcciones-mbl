# IE-006 — Infraestructura de alojamiento estático, DNS, SSL y capa de redirecciones

Plataforma CDN/edge en **Cloudflare Pages** encargada de servir el sitio estático compilado en Astro bajo `https://construccionesmbl.com/` (sin `www.` y con barra final `/`), ejecutar de forma declarativa las reglas `301`/`410` (`_redirects`), inyectar cabeceras HTTP de seguridad (`_headers`), alojar las funciones serverless de formularios y gestionar la transición DNS coordinada con el gestor actual de WordPress manteniendo intactos los registros `MX` del correo corporativo (resuelto en [[PA-006]] y [[ADR-007]]).
