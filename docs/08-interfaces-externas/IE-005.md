# IE-005 — Perfiles sociales Instagram y Facebook sin carga embebida pesada

Enlace seguro (`rel="noopener noreferrer"`) y declaración `sameAs` en Schema.org hacia los perfiles oficiales verificados:
- Instagram: `https://www.instagram.com/construccionesmbl`
- Facebook: `https://www.facebook.com/profile.php?id=61578248503214`

No se incrustan scripts de feed social de terceros en el DOM público para proteger las métricas CWV y la privacidad del visitante ([[PA-003]]).
