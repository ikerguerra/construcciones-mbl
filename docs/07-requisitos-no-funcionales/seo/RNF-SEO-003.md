# RNF-SEO-003 — Jerarquía única de encabezados H1–H3 y HTML semántico limpio

El sistema debe garantizar en cada vista exactamente un único elemento `<h1>` alineado con la intención de búsqueda principal antes que cualquier `<h2>` o `<h3>`, una jerarquía descendente sin saltos de nivel ni cifras decorativas marcadas como encabezados, y uso apropiado de etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`).
