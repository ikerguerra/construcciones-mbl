# RNF-SEO-006 — Optimización SEO de activos multimedia y atributos alt descriptivos

El sistema debe servir todas las imágenes de obras, servicios y artículos con nombres de archivo descriptivos en formato moderno comprimido, dimensiones explícitas (`width` y `height`), carga diferida en elementos bajo el pliegue y atributo `alt` único y descriptivo en el 100 % de las imágenes de contenido.
