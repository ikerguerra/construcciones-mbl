# RNF-ACC-001 — Cumplimiento WCAG 2.1 nivel AA y contraste sobre fotografías

El sistema debe cumplir las pautas WCAG 2.1 nivel AA garantizando un contraste mínimo de `4.5:1` en texto normal y `3:1` en texto grande, verificando explícitamente la legibilidad de textos y píldoras sobre imágenes mediante degradados protectores, ajustando el gris secundario (`--muted`) y evitando cursiva diminuta de bajo contraste en párrafos largos.
