# RNF-GEO-004 — Fichero de contexto semántico llms.txt para agentes generativos

El sistema debe publicar un fichero de texto estructurado `/llms.txt` en la raíz del dominio que sintetice en Markdown limpio la identidad de Construcciones MBL, datos NAP, catálogo de servicios en Asturias, rangos de precios orientativos y enlaces canónicos a las guías principales de *Innovación Sostenible*.
