# RNF-GEO-002 — Contenido estructurado AEO de respuesta directa y tablas comparativas

El sistema debe estructurar las páginas de servicio y los artículos del blog para facilitar la extracción directa de respuestas mediante un resumen inicial conciso (40–60 palabras con cifras y plazos concretos), encabezados en formato pregunta donde corresponda, listas ordenadas de fases y tablas HTML nativas (`<table>`) con encabezados `<thead>` para precios orientativos y comparativas.
