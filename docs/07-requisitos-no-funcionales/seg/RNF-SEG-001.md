# RNF-SEG-001 — Cumplimiento RGPD/AEPD en consentimiento de cookies y formularios

El sistema debe bloquear por defecto la ejecución de etiquetas analíticas o publicitarias hasta que el usuario otorgue consentimiento granular mediante botones equivalentes (*Aceptar*, *Rechazar*, *Configurar*), permitir revocar dicho consentimiento en cualquier momento desde el pie de página y asociar cada formulario a casillas no premarcadas y textos informativos en español.
