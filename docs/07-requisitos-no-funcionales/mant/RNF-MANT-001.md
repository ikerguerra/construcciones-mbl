# RNF-MANT-001 — Validación tipada de contenidos, precios y enlaces internos en compilación

El sistema debe validar en tiempo de compilación el esquema obligatorio de todos los servicios, proyectos, artículos, testimonios y promociones (títulos SEO, descripciones, categorías válidas, autores existentes, textos alternativos de imagen y fechas de vigencia), impidiendo desplegar compilaciones con metadatos incompletos o datos inconsistentes.
