# RNF-MANT-002 — Fuente única de datos corporativos (NAP, estadísticas y tarifas)

El sistema debe centralizar en un único origen de datos los atributos corporativos compartidos (razón social, CIF, dirección, teléfono, horario, estadísticas de trayectoria, valoración de reseñas y rangos base de tarifas), evitando duplicidades y contradicciones entre páginas visibles, simulador y JSON-LD.
