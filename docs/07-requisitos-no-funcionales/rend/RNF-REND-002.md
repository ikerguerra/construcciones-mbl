# RNF-REND-002 — HTML estático ligero y cero JavaScript en páginas informativas

El sistema debe generar HTML estático pre-renderizado reduciendo en al menos un 80 % el tamaño del documento respecto a los 354 KB del WordPress actual y evitando cargar JavaScript en el cliente en páginas puramente informativas salvo las islas interactivas estrictamente necesarias (navegación móvil, pestañas/carruseles, simulador, formularios y gestor de consentimiento).
