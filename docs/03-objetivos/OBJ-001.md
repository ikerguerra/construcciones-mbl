# OBJ-001 — Migración completa desde WordPress sin pérdida de tráfico orgánico

Trasladar todas las páginas corporativas, páginas de servicio y los 22 artículos editoriales de `construccionesmbl.com` desde WordPress hacia la nueva arquitectura estática, preservando o redirigiendo `301`/`410` el 100 % de las 393 URLs indexadas en los sitemaps heredados para evitar caídas de posicionamiento e indexación.

## Métricas de éxito
- 0 errores `404` sobre páginas, categorías y artículos válidos tras el corte.
- Eliminación del *index bloat* causado por las 340 etiquetas `/tag/` y `/author/3fwu9/`.
- Corrección de todos los defectos de migración y contenido heredados ([[Auditoria web actual WordPress]]).
