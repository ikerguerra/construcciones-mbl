# CU-008 — Publicar o actualizar artículos, proyectos y tarifas con validación

## Precondiciones
- Un miembro del equipo editorial o desarrollador prepara un nuevo artículo, actualiza la tabla de precios de un servicio o da de alta una nueva obra en el portfolio.

## Flujo principal
1. Edita la entrada correspondiente conforme al esquema tipado de cada entidad ([[Articulo]], [[Proyecto]], [[Servicio]], [[Promocion]]) siguiendo el flujo definido en [[PA-011]].
2. El proceso de compilación verifica obligatoriamente presencia de título SEO, meta descripción, autor válido, fecha, categoría válida, imagen con `alt`, fecha de vigencia de promociones y bloques resumen AEO.
3. Si existe un error estructural o una fecha promocional vencida sin marcar, el proceso detiene la publicación e informa el campo exacto.
4. Tras la verificación exitosa, genera el sitio estático actualizado y actualiza automáticamente `sitemap.xml` y metadatos estructurados.

## Flujos alternativos
- **A1 — Caducidad de promoción**: cuando una oferta temporal (como plato de ducha 48h) supera su `fecha_fin`, el sistema oculta automáticamente la vigencia caducada o muestra estado de tarifa vigente sin fecha vencida visible ([[PA-009]]).

## Postcondiciones
- Cero publicaciones con erratas de esquema, precios contradictorios o promociones caducadas en producción.
