# CU-002 — Simular presupuesto orientativo y solicitar estimación

## Precondiciones
- El usuario accede a `/calcula-el-precio-de-tu-reforma-en-asturias/`.

## Flujo principal
1. El usuario selecciona el tipo de proyecto (reforma integral, cocina, baño, construcción de vivienda, parcial o local), subtipo, metros cuadrados aproximados (con etiqueta contextual acorde al servicio elegido), nivel de calidades y ubicación en Asturias.
2. Opcionalmente marca trabajos específicos (electricidad, fontanería, aislamiento, humedades, carpintería exterior, suelo radiante/climatización, diseño a medida, gestión de licencias) y el plazo deseado.
3. El sistema muestra una horquilla orientativa transparente (si se confirma cálculo en vivo en [[PA-005]]) o valida los parámetros para elaborar el dossier personalizado.
4. El usuario introduce nombre, correo electrónico, teléfono y aceptación expresa de la política de privacidad en español, y envía la solicitud.
5. El sistema valida los campos, aplica protección antispam, remite el lead al canal comercial ([[PA-004]]) y muestra confirmación clara (o redirige a `/mensaje-enviado/`).

## Flujos alternativos
- **A1 — Error de validación**: si falta algún campo obligatorio o la casilla RGPD, el sistema muestra mensajes accesibles vinculados al campo sin borrar lo ya completado.
- **A2 — Fallo temporal de envío**: el sistema muestra un aviso amigable y ofrece llamada directa al `684 675 898` o WhatsApp para no perder el lead.

## Postcondiciones
- El lead queda registrado con todos los parámetros técnicos de su reforma y el evento de conversión queda listo para medición (si hay consentimiento).
