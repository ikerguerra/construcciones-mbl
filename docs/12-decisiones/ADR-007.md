# ADR-007 — Alojamiento estático en CDN edge, DNS y pipeline CI/CD

## Contexto
Para cumplir `TTFB < 200 ms`, soportar 393+ reglas `301`/`410` sin penalización de rendimiento, entregar cabeceras de seguridad HTTP y ejecutar funciones serverless de formularios sin mantener un servidor WordPress, conviene alojar en una plataforma moderna orientada a sitios estáticos y edge.

## Decisión
Desplegar en **Cloudflare Pages** con build continuo desde Git en `main`, aprovechando su red edge (`TTFB < 100 ms`), soporte nativo de Astro SSG, Cloudflare Pages Functions (`functions/api/lead.ts`) para formularios, y ficheros declarativos `_redirects` (393 reglas `301`/`410`) y `_headers` (seguridad HTTP y caché), ejecutando validación de esquema, generación de `sitemap.xml` y comprobación de enlaces rotos en CI (resuelto en [[PA-006]]).

## Consecuencias
- **Corte DNS**: se coordinará con el gestor actual de WordPress garantizando que los registros `MX` del correo corporativo permanecen intactos.
- **Limpieza pública**: se retira el enlace `Webmail` del pie de página público de la web corporativa.
