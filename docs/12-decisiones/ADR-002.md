# ADR-002 — Sistema visual editorial basado en mbl-maqueta y tokens CSS propios

## Contexto
El usuario ha suministrado [[mbl-maqueta.html]] como referencia visual y documentación de estilos para Construcciones MBL, caracterizada por marco blanco exterior redondeado (`36px`), alternancia entre bloques blancos y negros (`#000000`), píldoras glassmorphism, tipografía display `Bebas Neue` + `Inter` y color aportado por la fotografía arquitectónica.

## Decisión
Formalizar el diseño de [[mbl-maqueta.html]] mediante CSS moderno estructurado alrededor de tokens propios (`--black`, `--ink`, `--white`, `--bg`, `--muted`, `--line`, `--glass`, `--wood`, `--warm`) y adaptar los componentes genéricos inmobiliarios al catálogo de reformas y construcción en Asturias, incorporando ajustes de contraste WCAG 2.1 AA sobre `--muted`, tamaños de lectura larga y overlays de texto sobre imagen.

## Consecuencias
- **Positivas**: identidad diferencial alejada de plantillas WordPress, CSS mínimo sin sobrecarga de frameworks pesados y fidelidad completa a la maqueta aprobada.
- **Pendiente vinculado**: confirmación de fotografía real y logo SVG ([[PA-003]]) y adaptación exacta del buscador Hero y marca de agua ([[PA-007]], [[PA-014]]).
- **Documentación derivada**: [[Guia de estilos]], [[Web estilos y activos]].
