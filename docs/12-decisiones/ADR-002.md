# ADR-002 — Sistema visual editorial basado en mbl-maqueta y paleta corporativa MBL

## Contexto
El usuario ha suministrado [[mbl-maqueta.html]] como estructura visual base para Construcciones MBL —caracterizada por pantalla completa sobre blanco con margen de `16px`, bloques destacados con radios `36px`, Hero a alto y ancho de pantalla, tarjetas verticales, bloque oscuro alterno y Footer estructurado— y necesita dotarla de identidad cromática corporativa propia de la empresa (verde bosque `#0F1D14` / `#164624`, verde hoja `#3E6B47` / `#86D195` y superficies salvia `#EEF3EE`) sin tonos naranjas, además de animaciones fluidas sin penalizar Core Web Vitals y centrado editorial en artículos y FAQs.

## Decisión
Adoptar la estructura de layout de [[mbl-maqueta.html]] sobre CSS propio estructurado mediante tokens corporativos WCAG 2.1 AA/AAA (`--black: #0f1d14`, `--color-primary: #164624`, `--color-secondary: #3e6b47`, `--bg: #eef3ee`, `--bg-tint: #f3f7f4`, `--warm: #86d195`, `--wood: #2d6a3e`), tipografías `Bebas Neue` + `Inter`, iconografía SVG limpia y animaciones ligeras por CSS e `IntersectionObserver` respetando `prefers-reduced-motion`.

## Consecuencias
- **Positivas**: identidad diferencial corporativa propia alejada de copias literales monocromas, contraste verificado `>= 4.5:1` en toda la interfaz, peso HTML mínimo (`< 70 KB` en portada) y cero dependencias de frameworks pesados.
