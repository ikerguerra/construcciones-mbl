# ADR-001 — Adopción de Astro con generación estática (SSG) e islas interactivas

## Contexto
El sitio actual en WordPress + Elementor entrega 354 KB solo de HTML en portada, carga estilos y scripts bloqueantes y dificulta alcanzar métricas óptimas de Core Web Vitals. El sitio futuro de Construcciones MBL es eminentemente editorial e informativo con puntos interactivos acotados (navegación móvil, pestañas, carruseles, simulador, formularios y gestor de consentimiento).

## Decisión
Adoptar **Astro** en modo de generación estática (**SSG**) como base arquitectónica única para la web corporativa, hidratando únicamente componentes interactivos aislados (*Islands*) cuando sea estrictamente necesario.

## Consecuencias
- **Positivas**: HTML mínimo pre-renderizado, cero JavaScript en páginas de solo lectura, control total sobre etiquetas `<head>`, Schema.org y sitemap, y optimización nativa de imágenes y fuentes.
- **Riesgos / Mitigación**: las integraciones dinámicas (formularios, simulador) requieren una capa serverless ligera o webhook externo documentado en [[ADR-005]] y [[IE-001]].
