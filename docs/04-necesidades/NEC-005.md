# NEC-005 — Posicionar las páginas en búsquedas locales de Asturias, Gijón, Oviedo y Avilés

Dotar al sitio de metadatos on-page únicos, jerarquía semántica rigurosa, coherencia NAP y cobertura local estructurada para captar búsquedas con intención comercial en todo el Principado de Asturias.
