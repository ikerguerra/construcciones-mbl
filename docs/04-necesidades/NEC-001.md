# NEC-001 — Preservar la autoridad SEO y sanear la arquitectura de URLs heredada

Garantizar que todas las URLs actuales útiles sigan accesibles o redirigidas `301` y eliminar del índice las 340 etiquetas superfluas, el archivo de autor `3fwu9` y las páginas transaccionales sin valor de búsqueda.
