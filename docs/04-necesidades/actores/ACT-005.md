# ACT-005 — Rastreadores de buscadores tradicionales y motores IA

Agentes automáticos de indexación y extracción semántica (Googlebot, Bingbot, GPTBot, PerplexityBot, ClaudeBot) que consumen la web para evaluar rendimiento, arquitectura de URLs, marcado Schema.org, autoridad E-E-A-T y respuestas estructuradas.
