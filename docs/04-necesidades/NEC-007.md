# NEC-007 — Proyectar la estética editorial de mbl-maqueta de forma responsive

Mantener la coherencia visual de [[mbl-maqueta.html]] (bloques blanco/negro alternos, píldoras translúcidas, tipografía display `Bebas Neue` + `Inter`, tarjetas con degradado inferior) adaptada a escritorio y móvil sin perder usabilidad.
